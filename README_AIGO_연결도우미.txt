정선 AIGO · 로보독 연결 도우미

[처음 사용하는 Windows PC]
1. Python 3.10~3.14 중 하나를 설치합니다. Python 실행기(py launcher)를 포함하세요.
2. 배포 ZIP의 압축을 전부 풀고 AIGO_Install.cmd를 실행합니다.
   이 설치는 현재 사용자에게 aigo-robodog: 링크를 등록하고 .venv에 필요한 패키지를 설치합니다.
   관리자 권한은 필요하지 않습니다. 최초 설치에는 인터넷 연결이 필요합니다.
3. pawcare_control.html을 Chrome 또는 Edge에서 엽니다.
4. OUT 배송서비스에서 로보독 포트(기본 COM8)를 입력하고 '로보독 연결'을 누릅니다.
5. 브라우저의 연결 도우미 실행 요청을 허용합니다.
6. 로컬 관제 화면이 열리고 해당 포트로 연결합니다. '로보독 연결됨'을 확인한 뒤 배송을 시작합니다.

[동작]
- Python은 127.0.0.1:8765에서 백그라운드로 실행됩니다.
- 연결 버튼은 포트 연결만 수행합니다. 배송 시작은 별도의 배송 버튼으로 지시합니다.
- 기존 배송, 인물/QR 인식, 재난 대응 코드를 사용합니다.
- 운행 종료 후 연결을 유지합니다. 운행 중에는 연결 해제를 막습니다.
- 연결 해제는 로보독 세션을 닫습니다. 연결 도우미 서버는 계속 실행되어 재연결할 수 있습니다.
- 실행 중인 구버전 Python 서버가 8765 포트를 사용 중이면 먼저 종료하세요.
- ON 수신기 USB와 로보독 USB는 서로 다른 장치/포트입니다. Python의 micro:bit 수신 포트는 기본 COM10입니다.
- ON HTML은 자체 Web Serial을 사용합니다. Python이 COM10을 사용 중이면 ON에서 같은 COM10을 동시에 열 수 없습니다.

[웹 배포]
- 정적 사이트의 연결 버튼도 등록된 연결 도우미를 엽니다.
- 실제 제어는 해당 PC에 열린 로컬 관제 화면에서 이루어집니다.
- 각 로보독 연결 PC에서 최초 설치가 필요합니다.
- PC를 바꾸거나 폴더를 옮기면 그 폴더에서 AIGO_Install.cmd를 다시 실행하세요.
- 설치한 폴더를 삭제하지 마세요. 연결 도우미가 해당 폴더의 Python/HTML을 사용합니다.

[이 PC]
- 현재 작업공간 루트의 .venv를 사용하도록 설치됩니다.
- 실행 로그: 작업공간의 work\aigo-runtime\bridge.stderr.log 및 bridge.stdout.log

[확인 범위]
- 로봇 없이 API, 연결/해제, 중복 연결, 연결 오류, 화면 버튼 및 배포 파일을 검증했습니다.
- 실제 주행 및 기기 통신 성공 여부는 로보독을 연결한 뒤 확인해야 합니다.


[ON 순찰 · 데모데이 코드 연동]
- on_demo_original.py는 제공된 '로보독 데모데이.py' 원본과 동일한 파일입니다.
- aigo_on_patrol.py가 원본의 pyjuni 로보독 API, EyeDisplay, 안내 음성, 신호 중복 방지를 재사용합니다.
- 정사각형 고정 순찰 대신 지도에서 설정한 S→선택 순서→S 경로를 반복 순찰합니다.
- ON에서 로보독 연결 → 점 위치/순서/시작 방향 설정 → 순찰 시작 순서로 사용합니다.
- 로보독은 실제 S 위치에서 시작 방향을 맞춰 놓으세요.
- 이동 보정 기본 5cm/초는 추정값입니다. MOVE_SPEED=10에서 실제 측정해 수정해야 합니다.
- 지도 위치는 시간과 보정값으로 계산한 추정치이며, 실제 위치 센서의 측정값이 아닙니다.
- E/F/G/H 신호: 정지 → 눈 LED 표시(글자 순서 유지) → PC 한국어 음성 안내 → 1초 대기 → 순찰 재개.
- 회전 피드백이 10초 안에 확인되지 않으면 오류로 정지합니다.
- OUT과 ON은 같은 포트를 동시에 사용하지 않습니다. ON 시작 시 OUT 세션을 닫고 pyjuni로 제어권을 전환합니다.
- ON 정지 시 로보독 세션을 닫습니다. OUT 또는 ON을 다시 시작하려면 로보독을 재연결하세요.
- 수신기는 Python의 공통 수신기를 사용합니다. 기본 COM10이며 ON 신호를 원본 코드 처리기에 전달합니다.
- ON HTML의 USB 직접 연결은 수동 관측용입니다. 순찰 연결/시작 시 직접 연결을 해제합니다.
- PC에 Windows 한국어 음성(ko-KR)이 있어야 음성 안내가 됩니다. 음성 실행 오류가 나면 순찰을 정지합니다.
- 업데이트 전 연결 도우미 서버가 실행 중이면 종료하고 다시 시작하세요. 이미 실행 중인 프로세스에는 새 코드가 자동 적용되지 않습니다.
- 경로/일시정지/안내/재개/상호 배제와 HTTP API는 가짜 로봇으로 테스트했습니다. 실제 기기 주행은 별도 확인이 필요합니다.
