ON PC 수신기 실행 안내

`microbit_pc_receiver.hex`의 내장 소스를 확인했습니다. USB 115200 baud, radio group 1이며, 받은 무선 문자열을 `RX:E1` 같은 형식으로 전달합니다.
이 HEX는 제공받은 `microbit-PC 수신기 코드.hex`를 내용 변경 없이 복사한 것입니다.
이 수신기는 흔들어도 시험 신호를 보내지 않습니다.

사용 순서
1. 기존 ZIP과 구분하여 모두 압축을 풉니다.
2. Chrome 또는 Edge를 사용합니다. MakeCode의 데이터/시리얼 콘솔, Thonny,
   이전 관제 탭 등에서 수신기 포트를 열었다면 먼저 연결을 해제하세요.
3. 로컬에서 쓰면 기존 폴더의 index.html, pawcare_control.html을 이 버전으로 교체하고
   관제 화면을 새로고침합니다. Pages에서 쓰면 두 HTML을 본인 저장소에 덮어 올리고
   배포가 끝난 뒤 Ctrl+F5로 새로고침합니다.
4. ON → 수신기 연결 → PC USB 수신 micro:bit를 선택합니다. 로보독 포트와 구별하세요.
5. ON 수신기 영역에 새로 추가된 진단 문구를 확인합니다.
6. 별도 관측소 송신 micro:bit에서 라디오 그룹 1로 `E1` 같은 신호를 보냅니다.
   진단 화면에 `RX:E1`이 보이면 무선 수신과 USB 전달이 확인됩니다.

연결이 다시 끊기면 새 진단 문구의 [NetworkError: ...] 등 이름과 내용을 알려주세요.
이 오류 없이 실제 PC의 케이블·드라이버·포트 점유 중 어느 원인인지는 확정할 수 없습니다.

수정 사항
- 포트 선택/열기/읽기 실패를 화면에 계속 표시합니다.
- FramingError, ParityError, BreakError, BufferOverrunError에서는 읽기 스트림을
  해제하고 최대 3회 다시 읽습니다. 신호를 정상 수신하면 횟수를 초기화합니다.
- 수신 메시지 처리 오류가 USB 연결까지 종료하지 않도록 분리했습니다.
- 정상 연결 후 장치에서 스트림을 종료한 경우도 문구를 남깁니다.

검증
JavaScript 구문, 모의 연결 8개 시나리오, 새 HEX의 내장 소스와 `RX:E1` 파싱을 확인했습니다.
물리 USB 장치·Windows 드라이버에서 성공했는지는 이 환경에서 확인하지 못했습니다.
기존 서버·로봇 제어 코드는 변경하지 않았습니다.
