정선 AIGO 실행 오류 수정본

1. ZIP을 마우스 오른쪽 버튼으로 눌러 '모두 압축 풀기'를 선택하세요.
   ZIP 안에서 CMD 파일만 더블클릭하거나 다른 폴더로 복사하면 안 됩니다.
2. 압축을 푼 폴더에서 AIGO_Start.cmd를 더블클릭하세요.
   첫 실행에는 설치를 진행합니다. 인터넷 연결이 필요합니다.
   Python이 없다는 안내가 나오면 https://www.python.org/downloads/windows/ 에서
   Python 3.10~3.14 중 하나와 py 실행기를 설치한 뒤 다시 실행하세요.
   기존 Python 3.10~3.14도 설치 시 확인합니다.
3. 열린 로컬 관제 화면에서 실제 장치의 COM 포트를 선택하고 연결하세요.
   로봇 연결 및 운행 시작은 관제 화면의 버튼으로 별도 진행합니다.

말씀하신 '.psl'은 확장자 마지막 글자가 숫자 1인 '.ps1'입니다.
이 ZIP에는 AIGO_Install.ps1과 AIGO_Launch.ps1을 모두 포함했습니다.
두 PS1 파일과 두 CMD 파일은 같은 폴더에 두세요.
PS1 파일을 직접 더블클릭하지 말고 CMD 파일을 실행하세요.

문제 해결
- PS1 파일이 없다는 안내: 전체 ZIP을 다시 내려받고 모두 압축을 푸세요.
- 설치 오류: AIGO_Install.cmd를 실행하면 오류를 확인할 수 있습니다.
- 폴더를 이동했거나 예전 폴더가 없다는 오류: 새 폴더의 AIGO_Install.cmd를
  실행하여 브라우저 연결 도우미의 경로를 다시 등록하세요.
- 실행 중인 이전 서버가 있으면 종료하고 새 폴더에서 시작하세요.
- 서버 오류 기록: work\aigo-runtime\bridge.stderr.log
- 관리자 권한이나 PowerShell 실행 정책을 영구 변경할 필요가 없습니다.

수정 사항
- PS1 누락을 확인하고 전체 압축 해제 방법을 안내합니다.
- 최초 실행 시 설치하고, 누락되거나 이전 경로를 가리키는 설정은 다시 만듭니다.
- Python 버전을 확인하여 프로젝트 .venv에만 패키지를 설치합니다.
- 설치 후 로봇 라이브러리의 import를 검사합니다.
- 실패 시 오류 코드가 유지되고 시작 창에서 오류를 확인할 수 있습니다.

검증 범위
- PowerShell 구문 및 설치/실행 분기, ZIP의 필수 파일을 검증했습니다.
- Windows 11의 레지스트리 등록과 실제 로보독·micro:bit 통신 및 주행은
  이 환경에서 실행하지 못했으므로 실제 Windows PC와 장치에서 확인해야 합니다.
